AccessibilityAccesibilidad

A site that should work for more people, on more devices.Un sitio que debe funcionar para más personas y dispositivos.

We aim for clear structure, keyboard access, readable contrast, touch-friendly controls, reduced-motion support, and understandable form errors.Buscamos estructura clara, acceso con teclado, buen contraste, controles táctiles, reducción de movimiento y errores comprensibles.

Our approachNuestro enfoque

The site is built with semantic headings, visible focus styles, labeled form controls, responsive layouts, and support for the browser’s reduced-motion preference. We target WCAG 2.2 AA principles where practical.El sitio usa encabezados semánticos, enfoque visible, campos etiquetados, diseño adaptable y compatibilidad con la preferencia del navegador para reducir movimiento. Buscamos principios WCAG 2.2 AA cuando es práctico.

Need help using the site?¿Necesita ayuda con el sitio?

If you encounter an accessibility problem, tell us what page you were using and what went wrong. Contact contact@ulysessortiz.com.Si encuentra un problema de accesibilidad, díganos qué página estaba usando y qué pasó. Escriba a contact@ulysessortiz.com.
