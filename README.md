# Jardín de Ramiro

Public-facing flagship conversion layer. The original `index.html` remains untouched as the protected legacy master. Netlify rewrites `/` to `home.html`; the new pages reuse approved existing photography by reading the protected index at runtime.

Quote submissions use Netlify Forms (`ramiro-quote-request`). Email notification destination should be configured in Netlify Forms > Submission notifications as `contact@ulysessortiz.com`.
